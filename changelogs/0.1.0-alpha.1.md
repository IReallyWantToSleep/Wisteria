# 0.1.0-alpha.1

### ✨ 新增

* 帧生成
  * 通过 NVIDIA Streamline 接入 DLSS 帧生成后端
  * 通过 NVIDIA NGX 接入帧生成后端
  * 向 Super Resolution 注册帧生成后端，由其配置界面选择
* 低延迟
  * 通过 Streamline 接入 Reflex 低延迟支持
* 运行时
  * Streamline 运行时库随 jar 分发，首次启动时自行释放

### 📦 支持

* Minecraft 1.21.1、1.21.11、26.1、26.2，Fabric 与 NeoForge
* 需要安装 Super Resolution

---

### ✨ Added

* Frame generation
  * DLSS Frame Generation backend via NVIDIA Streamline
  * Frame generation backend via NVIDIA NGX
  * Backends register with Super Resolution and are selected from its config UI
* Low latency
  * Reflex low latency support via Streamline
* Runtime
  * The Streamline runtime ships inside the jar and extracts itself on first launch

### 📦 Supported

* Minecraft 1.21.1, 1.21.11, 26.1 and 26.2, on Fabric and NeoForge
* Requires Super Resolution to be installed
